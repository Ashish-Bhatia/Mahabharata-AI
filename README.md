# Mahabharata AI

One-stop AI application for exploring the Mahabharata.

## Project Governance

This repository is the system of record for the product.

- Product scope: GitHub Issues and `PROJECT_PLAN.md`
- Architecture decisions: `docs/adr/`
- Implementation: pull requests linked to Issues
- Delivery method: Agile Scrum, two-week sprints by default
- Main branch: protected delivery target

See `PROJECT_PLAN.md` for the delivery plan, engineering standards, quality gates, and initial backlog.
